Gallery management

Edit artworks

Choose a painting, edit its label or description, and optionally select a replacement image. Preview changes in this browser. To publish to everyone, download the updated files and upload them to your GitHub repository. This is a local editing tool, not a password-protected publishing system.

How to publish updates

1. Save edits and download gallery-data.js. 2. In your GitHub repository, replace the existing gallery-data.js with the downloaded file. 3. If you changed a picture, also download the replacement image and upload it to the repository root folder, replacing the file with the same name. 4. Commit the changes. Vercel redeploys your public gallery automatically if connected to that repository.

Important: changes saved in this browser are visible only on this device until published on GitHub. Anyone with the editor URL can open this page, but they cannot publish without access to your GitHub repository.

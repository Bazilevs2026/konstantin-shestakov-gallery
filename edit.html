GALLERY MANAGEMENT

Edit the collection

Edit artwork titles, descriptions, collection, and preview a replacement image. Changes are saved only in this browser until the downloaded files are committed to GitHub.

Publishing updates

Download the updated gallery-data.js and upload it to the root of your GitHub repository. For a changed image, upload the replacement JPG with the same filename to the same root folder. Commit the changes and Vercel will redeploy. The site uses the physical/digital frames already present in each image; frame-color metadata does not change those frames.

This browser editor is not password protected and does not itself publish the changes.

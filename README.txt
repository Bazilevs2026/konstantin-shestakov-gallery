KONSTANTIN SHESTAKOV — ART GALLERY

Open index.html to preview the responsive website. All 33 paintings and descriptions are included.

MOBILE: The gallery automatically adapts to phones, tablets, and desktop screens. Tap an artwork to enlarge it.

PUBLIC WEBSITE: Upload the contents of this folder to a GitHub repository connected to Vercel. Use a production deployment without Vercel Authentication to allow public visitors.

EDITING: Open /edit.html to edit titles, descriptions and collections, or preview replacement images. Click Save, then Download gallery-data.js. Commit this new file to your GitHub repository. For an image replacement, download the image with the original filename and commit it under artworks/. NOTE: edits made in a browser are NOT instantly public; the GitHub commit and Vercel deployment are necessary. edit.html is not an authenticated admin area.

To add more paintings, add images to artworks/ and add an entry in gallery-data.js (or artworks.json as a reference).

FRAME DESIGN: Every artwork now uses a coordinated mat-and-frame treatment.
To adjust any artwork frame color, open edit.html, select artwork, choose Frame color, save and download gallery-data.js, then publish to GitHub.
